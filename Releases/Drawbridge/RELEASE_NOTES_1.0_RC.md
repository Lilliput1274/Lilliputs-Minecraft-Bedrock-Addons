# Drawbridge 1.0 RC

Erster öffentlicher Release Candidate für **Minecraft Bedrock Edition**.

## Highlights

- **32 Brückengrößen**: Breiten 3, 5, 7, 9 und ungerade Längen 3–17
- **DDUI-Crafting** mit separaten Labels für Anker-Material, Kettenhalter und Brückenblatt-Material
- **Materialsuche** mit reaktiven Trefferlisten, Materialgruppen und Bildern
- **336 Materialdefinitionen** im geprüften Build
- **Redstone-gesteuerte Zugbrücken** mit animiertem Brückendeck
- **Optionale Kettenhalter** und Kollisionsschutz

## Download und Installation

1. Unter **Assets** die Datei **`Drawbridge_1.0_RC.mcaddon`** herunterladen.
2. Mit Minecraft Bedrock öffnen.
3. In der Welt **Behavior Pack und Resource Pack** aktivieren.
4. Im Kreativ-Inventar das Werkzeug **„Zugbrücke herstellen“** verwenden.

Vor der Installation in bestehenden Welten bitte eine Sicherung erstellen. **1.0 RC ist eine Vorabversion**, keine endgültige stabile Freigabe.
