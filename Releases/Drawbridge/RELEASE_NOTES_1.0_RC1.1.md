# Drawbridge 1.0 RC1.1

Zweiter Release Candidate für Minecraft Bedrock Edition; baut auf dem im Spiel bestätigten Scharnier-Fix aus Drawbridge 0.9.134 auf.

## Änderungen gegenüber RC1.0
- Korrigierte Drehachse: Das Brückenblatt schließt bei 90° sauber mit dem Anker ab.
- Überarbeitete Geometrie-Regressionsprüfungen.
- BP und RP auf 1.0.1 angehoben; Abhängigkeiten angepasst.
- DDUI, Materialauswahl, optionale Ketten und Redstone-Steuerung bleiben erhalten.

## Installation
Lade unter **Assets** die Datei `Drawbridge_1.0_RC1.1.mcaddon` herunter und öffne sie mit Minecraft Bedrock. Aktiviere BP und RP in der Welt. Vor Updates eine Sicherung deiner Welt erstellen.
