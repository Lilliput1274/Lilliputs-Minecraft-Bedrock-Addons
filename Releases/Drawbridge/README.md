## 🎮 Installation und Bedienung

1. `Drawbridge_1.0_RC.mcaddon` mit Minecraft **Bedrock Edition** öffnen.
2. In der Welt **Behavior Pack und Resource Pack** aktivieren.
3. Im Kreativ-Inventar den Gegenstand **„Zugbrücke herstellen“** verwenden.
4. Im DDUI **Anker-Material**, **Kettenhalter (optional)**, **Brückenblatt-Material**, **Breite** und **Länge** wählen.
5. **„Brücke erstellen“** anklicken, das Brücken-Item platzieren und mithilfe eines Redstone-Signals bedienen.

**Materialauswahl:** Die drei Materialnamen stehen als separate Labels **über** ihren Auswahlbuttons. Die Suche filtert passende Materialien während der Eingabe, Materialgruppen können aufgeklappt werden. Die Ergebnisliste hat keine künstliche Seitengrenze.

**Optionale Ketten:** Die Brücke funktioniert auch ohne Kettenhalter. Bei verwendeten Kettenhaltern muss ihre Platzierung geometrisch zur Brücke passen.

**Wichtig:** Diese Version ist ein **Release Candidate**. Vor Tests und Updates in bestehenden Welten bitte ein Backup anlegen.
