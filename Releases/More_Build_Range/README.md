# 📏 More_Build_Range

**Erweiterte Baureichweite für Minecraft Bedrock Edition.**

More_Build_Range ist ein eigenständiges Behavior Pack. Die Reichweite wird über Script-Events konfiguriert.

## Entwicklungsstand

**Version 1.5.0 – noch keine öffentliche Release-Freigabe.**

Laut aktueller Projekt-Dokumentation ist Version 1.5.0 in Entwicklung und basiert auf 1.4.4. Ein fertiges, hier zum Download angebotenes Release wird **erst nach erfolgreichem Test und Freigabe** ergänzt.

| Funktion | Aktueller Entwicklungsstand |
| --- | --- |
| Standardreichweite | 20 Blöcke |
| Einstellbarer Bereich | 6 bis 250 Blöcke |
| Fernabbau | Standardmäßig aus; per Befehl aktivierbar |
| Fortlaufendes Platzieren bei gehaltener Maustaste | Noch nicht umgesetzt |

## Steuerbefehle

```mcfunction
/scriptevent buildrange:help
/scriptevent buildrange:get
/scriptevent buildrange:set 25
/scriptevent buildrange:break on
/scriptevent buildrange:break off
/scriptevent buildrange:break get
/scriptevent buildrange:lang de-DE
```
