## 📥 Installation

**Minecraft-Add-ons:** `.mcaddon` per Doppelklick mit Minecraft Bedrock öffnen und in der Welt die benötigten Behavior- und Resource-Packs aktivieren. `.mcpack` importiert jeweils ein einzelnes Pack. Eine Sicherung bestehender Welten vor Updates wird empfohlen.

**Installer / Uninstaller:** Bitte zuerst die Hinweise auf der zugehörigen Projektseite beachten. Die Programme werden nicht als Minecraft-Packs importiert.
