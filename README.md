## ⬇️ Downloads

Die veröffentlichten Downloads erscheinen unter **[GitHub Releases](https://github.com/Lilliput1274/Lilliputs-Minecraft-Bedrock-Addons/releases)**. Für eine übersichtliche Sammlung erhält jedes Projekt einen eigenen Ordner unter `Releases/` mit Beschreibung und einem Link zu seinen Veröffentlichungen.

**Geplante eindeutige Release-Tags** verhindern, dass sich verschiedene Projekte im selben Repository gegenseitig überlagern:

- Drawbridge: `drawbridge-v1.0.0-rc1`
- More_Build_Range: `more-build-range-vX.Y.Z`
- Bulk-Installer / Uninstaller: `bulk-installer-vX.Y.Z`

**Aktueller Download-Stand:** Die Projektseiten sind eingerichtet. Binärdateien werden erst als öffentliche Release-Anhänge angeboten, wenn sie hier tatsächlich hochgeladen und geprüft wurden. Der bereits erfolgreich gebaute Drawbridge 1.0 RC ist vorerst über den [Actions-Build im Entwicklungsrepository](https://github.com/Lilliput1274/MineCraft_Addons/actions/runs/45000859962) erhältlich; dafür kann eine GitHub-Anmeldung erforderlich sein.

## 📥 Installation

**Minecraft-Add-ons:** `.mcaddon` per Doppelklick mit Minecraft Bedrock öffnen und in der Welt die benötigten Behavior- und Resource-Packs aktivieren. `.mcpack` importiert jeweils ein einzelnes Pack. Eine Sicherung bestehender Welten vor Updates wird empfohlen.

**Installer / Uninstaller:** Bitte zuerst die Hinweise auf der zugehörigen Projektseite beachten. Die Programme werden nicht als Minecraft-Packs importiert.
